LumutBlog - Technical Test Maganghub Lumut.id

Ini adalah repositori untuk LumutBlog, sebuah platform CMS berbasis Yii2 Framework. Aplikasi ini saya kembangkan untuk memenuhi tugas technical test program Maganghub di Lumut.id.

Fitur Utama

- Autentikasi dan otorisasi pengguna (Admin & Author).

- Manajemen artikel (Create, Read, Update, Delete / Soft Delete).

- Alur persetujuan artikel (Submit, Pending, Approve, Reject dengan catatan revisi).

- Sistem komentar interaktif dengan fitur moderasi dan lapor.

- Antarmuka responsif dengan desain bersih bertema hijau.
